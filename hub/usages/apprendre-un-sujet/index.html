Identification du terme d'animation

  • Terme exact : Origin-aware animation
  • Definition : L'element s'anime directement depuis son declencheur au lieu de son propre centre.
  • Variante proche : Scale in, si l'element grandit simplement sur place avec un fondu.
  • Autre alternative : Shared element transition, si le bouton lui-meme se metamorphose en panneau.
  • Usage recommande : Menus contextuels, infobulles et popovers modernes.

Comprendre les Promesses en JavaScript

Niveau 1 : « C'est comme commander un café : on te donne un bipeur. Tu continues ta vie, et le bipeur sonne quand le café est prêt. »

Niveau 2 : Une Promesse représente une valeur future issue d'un traitement asynchrone (en attente, résolue ou rejetée).

Exemple : fetch('/api/user').then(res => res.json()).catch(err => console.error(err));

À retenir : une promesse isole les temps d'attente réseau sans geler l'interface utilisateur.

Piège courant : oublier d'attraper les erreurs avec un bloc .catch(), ce qui masque les pannes silencieuses.

Fiche de guidage parent - Fractions CM1

Notion : Comparer des fractions simples de même dénominateur (ex : 3/5 et 4/5).

Pour vous : Le bas (dénominateur) dit la taille des parts, le haut combien on en prend.

Pour l'enfant : Imagine une pizza coupée en 5 parts égales. 4 parts, c'est plus que 3.

Méthode scolaire actuelle : Utiliser une bandelette graduée en 5 segments égaux.

Exercice d'entraînement 1 : Comparer 2/7 et 5/7 (Solution parent : 5/7 est plus grand).

Exercice d'entraînement 2 : Range dans l'ordre croissant : 6/8, 1/8, 4/8 (Solution : 1/8, 4/8, 6/8).
