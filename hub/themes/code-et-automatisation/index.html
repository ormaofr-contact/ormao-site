Diagnostic de panne d'authentification API

Diagnostic de panne d'authentification API

  • Trace d'erreur : Token JWT rejeté avec code 401 à la passerelle.
  • Vérification des flux : La clé secrète est bien transmise au conteneur.
  • Différence identifiée : Décalage d'horloge de 4 minutes sur le serveur de dev.
  • Hypothèse testée : La date d'émission du jeton apparaît dans le futur (nbf).
  • Test minimal validé : Synchronisation NTP manuelle résout le rejet.
  • Correctif ciblé : Ajout d'une tolérance d'horloge de 60 secondes dans la configuration.

Cycle TDD pour la validation d'email

  • Refactor : simplification de la règle de validation sans casser les tests.
