Comment l’installer

  1. Télécharge le fichier .zip, sans le décompresser.
  2. Dans Claude : Paramètres, Personnalisation (ou Capacités), section Skills.
  3. Clique sur « Importer un skill » et choisis le fichier.
  4. Fais ta demande : Claude applique le skill tout seul.

Ce que fait ce skill

Génère une liste précise de coupes temporelles pour supprimer hésitations, blancs et bafouillages de tes enregistrements.

Utile pour

  • Nettoyer les temps morts d'un podcast ou d'un tutoriel
  • Détecter automatiquement les faux départs et phrases répétées
  • Exporter une liste de coupes timecodées pour le montage

Exemple de demande

« Analyse ce fichier de sous-titres srt et dresse la liste des blancs et bafouillages à couper. »
