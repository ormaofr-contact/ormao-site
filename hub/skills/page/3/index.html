Priorite absolue : refondre les miniatures au format mobile pour rendre le sujet lisible en 0,5 seconde.

Action cette semaine : supprimer le texte secondaire sur les 3 prochaines vignettes et zoomer sur le visage.

Ce qui fonctionne deja : le rythme de parole sur les 3 dernieres intros et le choix des angles techniques.

Ce qu'il ne faut pas toucher : la regularite de publication du mardi soir qui fidelise l'audience actuelle.

Ce qu'il ne faut pas faire : changer de materiel video ou reecrire les scripts complets avant d'avoir regle le taux de clic.
