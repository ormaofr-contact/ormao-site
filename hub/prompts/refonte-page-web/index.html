Plan d'intervention UI SaaS B2B

1. Diagnostic : Hero section encombrée, taux de rebond mobile estimé à 62 %.

2. Architecture : Suppression du carrousel, mise en avant immédiate de la preuve sociale.

3. Composants : Réutilisation du bouton CTA primaire avec token padding-x porté à 24px.

4. Hiérarchie : Réduction de la taille du H1 de 48px à 40px sur mobile pour éviter la coupure.

5. Plan de sprint : Isolation du module de tarification avant intégration globale.

Le prompt

Tu es designer UX/UI senior et architecte frontend. Établis un plan complet de refonte pour la page web fournie sans toucher au code pour l'instant. Objectif : optimiser la hiérarchie visuelle, la clarté, la confiance et le taux de conversion, tout en conservant la stack technique existante. Voici le contexte ou le code actuel : [URL OU CODE SOURCE DU COMPOSANT]. Objectifs business et cible : [CIBLE ET OBJECTIFS DE CONVERSION]. Produis un document structuré en Markdown comprenant : 1. Audit de l'existant : friction UX, incohérences visuelles, accessibilité. 2. Architecture de l'information révisée section par section. 3. Inventaire des composants : décisions de réutilisation, d'extension ou de création. 4. Ajustements des jetons de design (couleurs, typographie, espacements). 5. Comportement responsive et ordre de mise en œuvre par étapes.
