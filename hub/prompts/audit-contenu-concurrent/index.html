Comment l’utiliser

  1. Copie le prompt ou ouvre-le dans ton IA.
  2. Remplace les passages entre crochets par tes informations.
  3. Envoie et récupère ton résultat.
  4. Pas convaincu ? Demande « plus court » ou « trois autres versions ».

Le prompt

Tu es un analyste en stratégie de contenu numérique. Voici les observations sur la présence sociale de mon concurrent principal : [COLLER OBSERVATIONS : THÈMES ABORDÉS, TYPES DE FORMATS, FRÉQUENCE, RÉACTIONS DU PUBLIC]. Analyse ces données sous 4 angles : 1. Ce qui génère le plus d'engagement chez eux et pourquoi, 2. Les faiblesses évidentes (formats délaissés, questions sans réponse dans les commentaires, ton trop impersonnel), 3. Les opportunités de différenciation pour [MON ENTREPRISE OU OFFRE], 4. Trois idées de publications pour nous positionner en alternative supérieure sur leurs thématiques fortes sans jamais les dénigrer directement.
