Feuille de route : Refonte CRM (6 semaines)

  • Phase 1 (S1-S2) : Audit des données existantes et nettoyage des doublons clients (Objectif : base 100 % saine)
  • Jalon 1 (Fin S2) : Validation du schéma de données par la direction commerciale
  • Phase 2 (S3-S4) : Migration technique et interconnexion API avec l'ERP de facturation
  • Phase 3 (S5) : Tests utilisateurs avec 5 commerciaux pilotes et ajustement des automatisations
  • Jalon 2 (Fin S5) : Accord formel pour bascule générale
  • Phase 4 (S6) : Formation des équipes, mise en ligne définitive et support renforcé
  • Risque identifié : Retard sur les webhooks API -> Action : session de dev dédiée bloquée en J12

Comment l’utiliser

  1. Copie le prompt ou ouvre-le dans ton IA.
  2. Remplace les passages entre crochets par tes informations.
  3. Envoie et récupère ton résultat.
  4. Pas convaincu ? Demande « plus court » ou « trois autres versions ».

Le prompt

Tu es directeur des opérations spécialisé dans la planification de projets à forte valeur ajoutée. Construis une feuille de route d'exécution détaillée pour le projet suivant : - Type de projet : [EX : REFONTE DE SITE, LANCEMENT PRODUIT] - Objectif principal : [RÉSULTAT ATTENDU] - Durée totale : [EX : 6 SEMAINES, 3 MOIS] - Composition de l'équipe : [ROLES ET RESSOURCES DISPONIBLES] - Priorité méthodologique : [RAPIDITÉ / QUALITÉ / COÛTS] Livrables requis : 1. Phases chronologiques avec objectif opérationnel précis pour chacune. 2. Tâches critiques ordonnées selon leurs dépendances réelles. 3. Échéances réalistes respectant la durée totale impartie. 4. Jalons de validation mesurables et points de contrôle qualité. 5. Principaux goulots d'étranglement identifiés et actions préventives associées. Présente le résultat sous une forme directement exploitable, sans justifications superflues.
