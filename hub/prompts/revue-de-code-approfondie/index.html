Audit de code : Contrôleur d'authentification

Gravité Haute · Faille d'injection SQL ligne 42 : utilisation d'une concaténation directe au lieu d'une requête préparée.

Correction proposée : remplacer db.query() par le paramétrage sécurisé avec placeholders.

Gravité Moyenne · Gestion d'erreur incomplète ligne 78 : promesse non interceptée pouvant bloquer le serveur Node.js.

Performance · Boucle N+1 ligne 115 : 12 requêtes synchrones évitables via un simple JOIN en amont.

Recommandation : extraire la logique de hashage de mot de passe dans un middleware dédié.

Comment l’utiliser

  1. Copie le prompt ou ouvre-le dans ton IA.
  2. Remplace les passages entre crochets par tes informations.
  3. Envoie et récupère ton résultat.
  4. Pas convaincu ? Demande « plus court » ou « trois autres versions ».

Le prompt

Agis en réviseur de code senior et intraitable. Analyse le code fourni et structure ton audit technique selon cinq axes précis : 1. Qualité du code : repère les anti-patterns, la dette technique, les nommages imprécis et les pistes de refactorisation. 2. Détection de bugs : identifie les erreurs logiques, les cas limites non traités et les risques liés aux valeurs nulles ou indéfinies. 3. Sécurité : signale les vulnérabilités critiques (injections, failles XSS, gestion laxiste des entrées utilisateur ou des autorisations). 4. Performance : isole les requêtes redondantes, les fuites de mémoire potentielles et les traitements inutilement lourds. 5. Bonnes pratiques : vérifie l'adhérence aux idiomes du langage, la gestion robuste des exceptions et propose une stratégie de tests unitaires.
