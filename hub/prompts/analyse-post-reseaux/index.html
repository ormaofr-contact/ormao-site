Comment l’utiliser

  1. Copie le prompt ou ouvre-le dans ton IA.
  2. Remplace les passages entre crochets par tes informations.
  3. Envoie et récupère ton résultat.
  4. Pas convaincu ? Demande « plus court » ou « trois autres versions ».

Le prompt

Tu es analyste en veille stratégique et créateur de contenu. Voici un post ou fil issu de réseaux sociaux : [COLLE LE TEXTE OU DÉCRIS LE POST VIRAL]. Réalise une analyse approfondie selon ces étapes : 1. Extraction des faits : résume les affirmations principales, statistiques citées, arguments avancés et le contexte sous-jacent. 2. Vérification et fact-checking : évalue la véracité des chiffres, signale les biais, les raccourcis logiques ou les données tronquées. 3. Sources complémentaires : apporte 2 ou 3 contre-arguments documentés ou faits notables non mentionnés dans le post original. 4. Exploitation de contenu : propose 2 formats de republication prêts à poster (par exemple : un thread pédagogique nuancé ou un post LinkedIn professionnel) pour tirer parti de ce sujet d'actualité avec crédibilité. Adopte un ton objectif, tranchant et rigoureux.
