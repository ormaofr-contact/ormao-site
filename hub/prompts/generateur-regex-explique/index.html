Validation de numéro mobile français

Expression : ^(?:\+33|0)[67](?:[ .-]?[0-9]{2}){4}$

^ et $ : délimitent le début et la fin exacte de la chaîne testée.

(?:\+33|0) : accepte l'indicatif international (+33) ou le zéro initial.

[67] : cible exclusivement les préfixes mobiles 06 et 07.

(?:[ .-]?[0-9]{2}){4} : valide 4 groupes de 2 chiffres avec espace, point ou tiret facultatif.

Exemples valides : 06 12 34 56 78, +33712345678, 06.12.34.56.78

Exemple de résultat

Comment l’utiliser

  1. Copie le prompt ou ouvre-le dans ton IA.
  2. Remplace les passages entre crochets par tes informations.
  3. Envoie et récupère ton résultat.
  4. Pas convaincu ? Demande « plus court » ou « trois autres versions ».

Le prompt

Tu es un expert en expressions régulières (Regex). Conçois la regex optimale selon le besoin suivant. Besoin : - Ce que la regex doit capturer ou valider : [EX : FORMAT DE TÉLÉPHONE FRANÇAIS, ADRESSE EMAIL, EXTRAIRE UN PRIX] - Langage ou outil cible : [JAVASCRIPT, PYTHON, PHP, GOOGLE SHEETS, PCRE] - Exemples de chaînes valides : [EXEMPLES POSITIFS] - Exemples de chaînes non valides : [EXEMPLES NÉGATIFS] Livrables attendus : 1. L'expression régulière brute avec les modificateurs requis (flags). 2. Une décomposition élément par élément expliquant le rôle de chaque symbole. 3. Un extrait de code minimal dans le langage spécifié démontrant la validation et l'extraction. 4. Les éventuels pièges ou limites de performance de cette expression.
